# 大螢幕模式獎項切換升級規劃方案

升級大螢幕（投影模式）的獎項切換機制，將原本僅能透過微調按鈕左右單步切換的方式，升級為**「下拉選單直選 ＋ 左右步進 ＋ 鍵盤快捷鍵（←/→/P）」**的全方位便捷切換體驗，讓尾牙控台人員與主持人在大螢幕現場能瞬間直達任一獎項。

---

## 核心決策與使用者確認

> [!IMPORTANT]
> **已確認方案**：依使用者選擇，採用 **「下拉選單直選，搭配左右鍵與鍵盤快捷鍵」**。
> - **直選選單**：點擊頂部中央獎項名稱即可展開全獎項速查下拉選單，標示獎項進度（待抽、進行中、已完抽）。
> - **微調按鈕**：保留並優化左右箭頭（`<` / `>`），支援上一獎項 / 下一獎項步進切換。
> - **鍵盤快捷鍵**：支援大螢幕模式下的鍵盤快速控制（`←` / `→` 切換獎項、`P` 鍵開啟/收合獎項清單、`ESC` 關閉選單）。

---

## 1. 系統功能與使用體驗 (UX Flows)

### A. 頂部導覽列切換器升級
* **觸發按鈕（Trigger Button）**：
  - 位於大螢幕頂部中央，顯示當前獎項名稱、獎項內容、抽出進度（例：`特獎：iPhone 16 Pro (0/1)`）及向下箭頭圖示 `ChevronDown`。
  - 當前若為「現場特別加碼獎」，帶有醒目的加碼徽章。
  - 游標懸停時呈現琥珀色溫潤陰影與按鈕反饋，點擊即展開「全獎項快速選單」。

### B. 豐富狀態的獎項下拉式選單 (Prize Dropdown Popover)
* **清單呈現方式**：
  - 依獎項排序（自第一道獎項至最後一道加碼獎項）完整列出。
  - 每個獎項項目清晰顯示：
    - **獎項名稱與獎品內容**（例如：`頭獎` - `MacBook Pro 16吋`）。
    - **抽獎進度狀態**：
      - 🟢 **已完抽**：綠色勾選圖示，標註配額已全數抽出（如 `5/5 名額滿`）。
      - 🟡 **進行中**：金色呼吸燈點，標註已抽出與剩餘名額（如 `2/5，剩餘 3 名`）。
      - ⚪ **尚未開始**：標註待抽（如 `0/10`）。
    - **當前選中標記**：正在大螢幕顯示的獎項具金紅色微光外框與核選標記。
  - **點擊即跳轉**：點選任一獎項後，立即平滑切換大螢幕的主獎項資訊與得獎者清單，並自動關閉選單。
  - **點擊外部或 ESC 自動關閉**：具備 Click-Outside 偵測與 `ESC` 鍵關閉機制，不影響大螢幕主視覺。

### C. 左右步進按鈕與快捷鍵操作
* **左右切換按鈕**：
  - 位於下拉選單觸發按鈕左右兩側，一鍵切換至「上一獎項」與「下一獎項」。
  - 首個獎項或最後一個獎項時，對應按鈕自動禁用並降低透明度。
* **鍵盤快捷鍵（全域支援）**：
  - `←` (`ArrowLeft`) 或 `PageUp`：快速切換至前一個獎項。
  - `→` (`ArrowRight`) 或 `PageDown`：快速切換至下一個獎項。
  - `P` 鍵：快速開啟 / 關閉獎項下拉選單。
  - `Space`：開始抽獎 / 停止抽獎（維持原有快捷鍵）。
  - `ESC`：選單開啟時優先關閉選單；選單關閉時則為退出大螢幕投影模式。
  - 頂部輔助提示：在按鈕旁提供輕巧的 `[←/→]` 鍵盤標籤，提升控台操作指引。

## 3. 實作細節與修改範圍

1. **`src/components/ProjectorView.tsx`**：
   - 新增狀態 `isPrizeMenuOpen: boolean` 用於控制下拉選單的開關。
   - 新增下拉選單容器與觸發器 ref，實作點擊外部關閉（Click Outside listener）。
   - 擴充 `handleKeyDown` 鍵盤監聽事件：
     - 當 `isDrawing` 為 false 且非抽獎進行中時，支援 `ArrowLeft`、`ArrowRight`、`KeyP`。
     - 當下拉選單開啟時，按 `Escape` 優先關閉選單而不退出投影模式。
   - 將原本 `hidden md:flex` 的簡易膠囊改為現代化、支援所有螢幕尺寸的自適應複合切換器：
     - 左箭頭按鈕 (`ChevronLeft`)
     - 中央直選觸發按鈕（顯示當前獎項、抽中比例、下拉指標圖示）
     - 右箭頭按鈕 (`ChevronRight`)
     - 下拉選單彈出層（含各獎項狀態指示標籤、配額進度條）
2. **無障礙與防呆機制**：
   - 抽獎動畫進行中（`isDrawing = true`）鎖定獎項切換功能，防止動畫中途資料錯亂。
   - 鍵盤快捷鍵在彈出對話框（如加碼 modal、捐贈 modal）開啟時自動停用，避免事件衝突。
