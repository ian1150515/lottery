# 🎊 尾牙智能抽獎系統 (Gala Draw 2026)

專為企業尾牙（年終聚餐）、春酒與大型晚會打造的高規格**全功能雙獎池智能抽獎與活動管理系統**。具備高雅熱鬧的「中國紅 × 祥瑞金」喜慶尾牙視覺、大螢幕 LED 投射、全自動防弊滾動模式、正規/加碼雙獨立獎池、防當機安全快照恢復，以及兼顧活動現場與後台維護的三頁分流架構。

- **`goldShimmer` 金箔流光掃描**：於抽獎滾動插槽、重點標題與金色按鈕（`festive-gold-btn`）邊緣加入柔滑的 45 度角度流光動畫，營造貴金屬光澤。
- **`pulseGlow` 祥瑞呼吸光環**：於大螢幕投影得主姓名、特別獎項及開獎定格瞬間提供柔和的金紅色擴散光暈。

  - `festive-gold-btn`：採用 `from-[#fef08a] via-[#facc15] to-[#d97706]` 搭配深酒紅黑字與立體投影，點擊時具備自然縮放回饋。

## 🌟 前台抽獎頁面規格 (Frontend)

### 2.1 頁面標題與視覺呈現
- **動態活動標題醒目橫額 (`FestiveHeaderBanner.tsx`)**：
  - 頁面正上方醒目顯示由後台管理者設定的「本次抽獎標題名稱」。
  - 搭配高雅金質邊框、紅金雙色立體字形與典雅中國結/紅燈籠視覺點綴，營造滿滿儀式感。
- **全頁面重要資訊字體加大優化**：
  - 全面加大「中獎名額 / 剩餘名額」即時數據（`text-3xl` ~ `text-5xl`），確保現場長距離觀看一目了然。
  - 候選人高速滾動姓名全面擴大為 `text-5xl` ~ `text-7xl`，投射大螢幕時尊榮大器。

### 2.2 多元中獎慶祝特效 (Celebration Dynamics)
系統支援 5 大高規格隨機或自訂切換的慶祝粒子特效，每次抽出得主時隨機或輪替展現：
1. **雙側加農砲彩帶 (Streamers)**：兩側底部向中心同時射出金紅交織的長彩帶。
2. **璀璨星辰流金雨 (Golden Stars)**：從頂部落下如流金般的五角星星與金色碎屑。
3. **喜慶禮炮煙火彈 (Fireworks)**：多發禮炮在空中綻放的煙火散開效果。
4. **滿堂吉慶落花雨 (Festive Rain)**：全螢幕飄落高雅紅金色碎紙花雨，持續且密集。
5. **祥瑞旋風環形噴發 (Whirlwind)**：由中央圓形向四周放射性擴散的華麗環形噴發。

### 2.3 中獎星光榜（得獎紀錄）
- **專業 HTML `<table>` 表格結構**：
  - 採用結構化表格呈現即時與歷史中獎名單，取代傳統鬆散卡片排版。
  - **表格必備欄位**：
    1. **項次**（流水號 `#1`, `#2`...）
    2. **員工工號與姓名**（附帶部門標籤）
    3. **中獎獎項**（特獎、頭獎...，附帶正規/加碼獎池徽章）
    4. **獎品內容**（包含獎品照片縮圖預覽）
    5. **開獎時間**（年月日時分秒完整時間戳記）
    6. **中獎狀態與棄權備註**（正常領獎 / 唱名三次未到已補抽）
    7. **操作**（未到場即時補抽按鈕）
- **即時搜尋與篩選**：支援按員工姓名、工號、部門關鍵字搜尋，並可按獎項類別單獨過濾。
- **雙規格名單匯出**：支援匯出 `.xlsx` 格式與防亂碼的 `.csv`（UTF-8 BOM）。

## ⚙️ 後台管理頁面規格 (Backend)

### 3.1 抽獎活動基本設定
- **動態自訂活動標題**：
  - 提供輸入欄位，管理者可自由修改「本次抽獎的標題名稱」。
  - 儲存後立即同步更新至前台頂部橫額、大螢幕投影頁面及瀏覽器分頁標題。
  - 內建常用尾牙/旺年會/春酒活動標題範本，一鍵快速套用。

### 3.2 抽獎節奏參數設定
- **自訂轉動與揭曉秒數**：
  - 提供滑桿與數字輸入框，可自由調整按下抽獎後到結果揭曉的「等待/轉動時間」（支援 1.0 ~ 10.0 秒，預設 3.2 秒最佳懸疑節奏）。
  - 前台抽獎舞台與大螢幕投影頁面將嚴格依此秒數進行高速輪巡並在最後 35% 時間自然平滑減速定格。
  - 提供「⏱️ 試跑節奏」即時模擬倒數測試按鈕。
- **多元慶祝特效模式切換**：
  - 可選擇「隨機精彩輪替（推薦）」或固定指定任一種特效。
  - 提供「🎉 立即試噴」按鈕，便於管理者在活動前實機驗證。

### 3.3 獎項與獎品資料庫管理
- **完整獎項管理**：
  - 支援設定獎品圖片（可直接本機上傳圖片檔案生成即時預覽、填入圖片網址、或選用內建高畫質範本圖）。
  - 設定獎項級距（如：特獎、頭獎、二獎、三獎、普獎、現場加碼）。
  - 設定獎品具體內容（例如：iPhone 17 Pro Max 256GB、Dyson Supersonic 吹風機）。
  - 設定總名額配額（Quota）。
  - 支援所屬獎池設定（正規抽獎池 / 老闆加碼池）。
- **完整 CRUD 操作**：
  - 點擊「新增抽獎獎項」彈出專屬表單彈窗。
  - 點擊獎項卡片之「編輯」可即時修改資訊或置換照片。
  - 點擊「刪除」具備防呆確認機制（若已有中獎紀錄會給予明確安全提示）。
- **保留 Excel 上傳匯入**：
  - 依然支援透過 Excel 檔案批次匯入獎項清單，並自動進行欄位容錯比對。

## 📊 資料格式與匯入規格

### 1. Excel 檔案匯入 (`.xlsx` / `.xls`)
可上傳單一活頁簿（包含兩個工作表），或分別上傳。系統具備智慧標題自動模糊比對容錯能力：

#### 工作表一：【員工名單】
| 建議欄位名稱 | 支援容錯標題 | 必填 | 說明 |
| :--- | :--- | :---: | :--- |
| **工號** | 工號, 員工編號, EmpNo, No, ID | 是 | 唯一識別，如 `EMP-001` |
| **姓名** | 姓名, 員工姓名, Name, EmployeeName | 是 | 員工全名，如 `陳冠宇` |
| **部門** | 部門, 所屬部門, 單位, Department, Dept | 否 | 顯示於中獎卡片，如 `研發部` |

#### 工作表二：【獎品清單】
| 建議欄位名稱 | 支援容錯標題 | 必填 | 說明 |
| :--- | :--- | :---: | :--- |
| **順序** | 順序, 排序, 順位, Order, Seq | 否 | 抽獎順位（建議由小獎到大獎） |
| **獎項名稱** | 獎項名稱, 獎項, 名稱, Prize, PrizeName | 是 | 如 `特獎`、`頭獎`、`普獎` |
| **獎品內容** | 獎品內容, 獎品, 內容, Content, Item | 是 | 如 `iPhone 17 Pro Max 256GB` |
| **名額** | 名額, 數量, 配額, Quota, Count, Qty | 是 | 數字，如 `1`、`5`、`10` |
| **獎池分類** | 獎池, 類別, 分類, Pool, PoolType | 否 | 填入 `main`（正規）或 `bonus`（加碼），預設為 `main` |

## 🚀 晚會現場實戰推薦作業流程

1. **活動前一至二天（資料準備）**：
   - 進入【⚙️ 後台管理者】，至「抽獎活動與節奏設定」輸入晚會標題名稱與期待的轉動秒數。
   - 至「獎項與獎品管理」新增或編輯獎品，上傳精美獎品圖片。
   - 至「Excel 匯入與範本」匯入正式員工名冊。
   - 點擊「下載完整歷程備份檔 (JSON)」存於 USB 作為離線雙重備援。
2. **活動前一小時（彩排測試）**：
   - 點擊「載入彩排測試資料」，系統跳出「彩排測試資料確認視窗」，顯示現存名單防呆警示與 50 位跨部門員工及 5 個級距獎項規格，點擊確認後完成載入。
   - 測試投影機大螢幕切換、測試單抽、批次抽、音效及缺席補抽。
   - 彩排結束後，重新匯入正式名單。
3. **活動進行中（現場抽獎）**：
   - 主控台開啟【🎪 現場抽獎舞台】（或外接螢幕開啟【大螢幕模式】）。
   - 依序抽出正規獎項；正規抽完後依系統導引切換至【★ 老闆加碼專區】。
   - 若老闆現場臨時宣佈加碼現金或加碼獎，點擊「+ 現場加碼」即可即時設定並抽出。
4. **活動結束（清冊產出與個資銷毀）**：
   - 進入【🏆 中獎星光榜】或【⚙️ 後台管理者】，點擊「匯出中獎名單 Excel」或「匯出 CSV」。
   - 確認檔案妥善保存後，於後台點擊「結束活動清除快照」，徹底清空瀏覽器暫存個資，圓滿落幕！
